When NOT to use XML Formatter

  • Well-formed is not the same as valid — this checks XML syntax, not conformance to a specific XSD/DTD schema.
  • Comments and processing instructions are preserved as-is in place, but the formatter will not reformat the inside of CDATA sections or preformatted content.

Questions people ask

Is my input sent to a server?

No. This tool runs entirely in your browser using JavaScript. Nothing you paste is uploaded, stored, or sent anywhere.

Does it validate as well as format?

Yes. The XML is parsed with the browser's strict XML parser; if the document is malformed, the tool shows the parser's error instead of output, so a successful format means the XML is well-formed.

Can I choose the indent size?

Yes — 2 spaces, 4 spaces, or a tab. Attributes stay on the same line as their element, matching common XML style.
