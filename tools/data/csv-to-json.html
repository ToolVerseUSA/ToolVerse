Questions people ask


Does it handle quoted values with commas?
Yes — values wrapped in double quotes may contain the delimiter, and doubled quotes ("") become a single quote character, per common CSV conventions.


How is the header row used?
The first row becomes the property names of each JSON object. Every other row becomes one object in the output array.


Is my data sent anywhere?
No. Everything is parsed locally in your browser. Nothing is uploaded or stored.
